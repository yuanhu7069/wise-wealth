## 1. 元信息补充

### 1.1 优先级理由

「免费层告诉你怎么做，Plus 层告诉你为什么是这个数」是产品定位一句话，但 Plus 至今完全空白——方案页给的是一张「对」的表，推理链数据 B 期起就随方案冻结在库，界面上却一个字都没有。P1 是 Plus 的第一块，也是产品 PRD §5.10 唯一标 P0 的差异化能力；数据就位使其成为投入产出比最高的 Plus 起步。T4 季度复盘是产品 PRD §4.4.3 追踪清单中唯一未动工的免费项，快照已开始积累，季度节拍（月度快照 → 季度复盘的复访闭环，§2.2）缺最后一环。

### 1.2 状态流转

本 PRD 过附录 A 自检后由苑问确认（2026-09-27 grilling 两轮拍板即确认动作）；执行期以 `.scratch/h-plus/` 工单推进（同批产出，见 h-plan）。

## 2. 背景与目标

### 2.1 问题陈述

唯一用户（苑问）在 G 期后拥有完整 Phase 1（4 个 L1 模式 + 问卷 + 方案 + 追踪 + 知识库 + 对比），但两个缺口仍在：① 方案页的每个数字只是结果——「应急月数为什么是 9」「投资桶为什么归零」这些推理（B 期起已随方案版本冻结在库）没有任何承载界面，产品定位的后半句「Plus 告诉你为什么」无从体验，分层设计停留在字段层面；② 追踪只有月度视角——偏离提醒看「这个月」，但「这一季坚持得怎么样、缺口收敛得多快」没有答案，产品 PRD §2.2 复访闭环的季度节拍（⑤ 季度复盘）缺失。该问题在每次生成方案、每次想评估「这套方法我坚持得下去吗」时出现，导致「推理可追溯」这一核心差异化资产与「持续用下去」的复访闭环各缺一角。

### 2.2 目标与价值

- 价值类型：作品完整性（主：产品定位后半句第一次成真）+ 自用提效（看懂自己的方案、季度回望）+ 分层机制奠基（tier 闸门到位，未来接支付只换开通方式）
- 目标1：plus 会话可在方案页展开完整推理链（应急金三规则 + 让位链），链条与问卷答案、方案数字逐节点一致
- 目标2：free 会话可见「还有一层」的入口与模糊示意，闸门在服务侧——响应体里没有内容可偷
- 目标3：季度复盘页上线，三件内容（坚持月数 / 各桶变化 / 缺口收敛）口径与月度追踪一致，特殊月不计入环比
- 本期不追求：支付与产品内升级路径（OUT-001）、假设面板与情景推演（OUT-002）、复盘 Plus 叠加（OUT-006）

## 4. 用户故事与验收标准

### 4.1 核心用户故事

- US-H-1（看懂数字）：作为唯一用户，我希望在方案页展开推理链，逐节点看到「收入稳定性 → 应急月数 → 应急目标 → 每月转入（→ 让位）」的因为所以，以便知道「为什么是这个数」而不只是信一个结果。
- US-H-2（分层体验）：作为唯一用户，我希望在 free 态看到「为什么」入口、模糊的链条形状与一句示例，以便体验「免费告诉你怎么做、Plus 告诉你为什么」的分层设计——知道自己缺什么。
- US-H-3（季度回望）：作为唯一用户，我希望每季度看到一份复盘——坚持了几个月、各桶变化多少、应急缺口收敛得多快，以便获得继续下去的理由，并发现「该重新生成方案了」的信号。
- US-H-4（口径一致）：作为唯一用户，我希望复盘的数字口径与月度追踪完全一致（特殊月不作环比基准、已坚持月数是总量不是连续性），以便两处不打架。

### 4.2 验收标准（Given-When-Then）

**推理链与分层闸门（P04）**

- **AC-1（正常）**：Given plus 会话打开 P04，When 点击应急金状态区的「为什么」入口，Then 展开「因为 → 所以」链条：每节点 = 规则名 + 输出值 + 一句话依据（如「收入稳定性=波动大 → 9 个月」），金额等宽千分位右对齐，收展可往返（aria-expanded）。
- **AC-2（正常）**：Given 任一 active 方案，When 展开链条，Then 覆盖应急金三规则（月数 / 目标 / 月转入节奏）；**当 safety_first 让位发生时**（收入不足档案）链条含让位节点，如实呈现「投资桶归零 / 规则桶缩减 → 缺口提示」；未发生时无该节点、不占位。
- **AC-3（边界）**：Given free 会话打开 P04，When 查看「为什么」入口，Then 点击后展示 Plus 徽章 + 模糊占位（链条形状可见、内容不可读）+ 一句示例 + 「N 步推理」计数；完整内容任何状态下不可读。
- **AC-4（边界·闸门）**：Given free 会话，When 直接请求方案接口，Then 响应体**不含**推理链内容字段（仅条数）——curl 断言，服务侧过滤而非前端遮罩；随后经运维脚本置 plus，**无需重新生成方案**，刷新 P04 即见完整链条（tier 实时生效）。
- **AC-5（异常）**：Given 会话过期，When 展开推理链或打开 P09，Then 内联过期错误 + 重登链接（`from=` 回跳，沿 F/G 期先例）。
- **AC-6（正常）**：Given 修改问卷答案后重新生成方案，When 展开新 active 方案的推理链，Then 链条按新档案重算、与方案页数字逐节点一致；与既有 preview 对账单测同源回归（引擎增补不破对账）。

**季度复盘（P09）**

- **AC-7（正常）**：Given 已登录（任意 tier），When 从 P05 追踪页进入 P09（`/tracking/review`），Then 默认展示当前自然季度，`page_view`（page_id=p09）埋点可查。
- **AC-8（正常）**：Given 所选季度有 ≥2 条快照，When 查看复盘，Then 三件内容齐备：① 已坚持月数（全部快照累计，非季内、非连续）；② 各桶季内变化（季末快照 − 季初快照，带符号、负数红字）；③ 应急缺口收敛（季初缺口 → 最新缺口 + 月均收敛额 + 「按当前速度约 N 个月攒满」距离感表述）。
- **AC-9（边界）**：Given 季内含「本月特殊」快照，When 查看复盘，Then 该月**计入**已坚持月数、**不计入**环比基准（变化与收敛速度计算剔除其环比），页面上有「本月特殊，未计入变化」的标注（RULE-024 延续）。
- **AC-10（边界）**：Given 所选季度无快照，When 打开 P09 或切换到该季，Then 空态文案 + 「去录入本月快照」引导回 P05；仅 1 条快照的季度显示单点形态（变化为 0 并标注「本季仅 1 条快照」），不破版。
- **AC-11（边界）**：Given 直链携带非法 quarter（格式错 / 越界年份），When 打开 P09，Then 服务侧 422、页面呈现可理解的错误文案，不白屏；页内季度切换器只产生合法值。
- **AC-12（边界）**：Given 375px 宽度与亮/暗两态，When 走查 P09 与 P04 推理链区，Then 不破版；复盘不出现抽象完成度百分比（距离感口径，CONTEXT.md「距离感进度条」）。
- **AC-13（异常）**：Given 复盘取数失败（网络中断），When 页面发起请求，Then 错误态 + 重试入口，已渲染内容不丢失。
- **AC-14（正常）**：Given free 会话，When 完整走 P09（当前季 → 切换季 → 空态），Then 功能与 plus 完全一致（复盘免费全量，RULE-051）——分层不碰追踪。

**场景覆盖自查**：正常（AC-1/2/6/7/8/14）、异常（AC-5/13）、边界（AC-3/4/9/10/11/12）——三类齐备。

## 5. 功能范围

### 5.1 包含（In Scope）

- [ ] FEATURE-001：Plus 闸门——启用账号分层字段（free/plus），服务侧按 tier **实时**过滤推理链；free 仅得条数与占位素材；置 plus 走运维脚本（产品内无购买/升级路径）

- [ ] FEATURE-003：方案接口暴露推理链——active 方案响应增推理链内容（tier 闸门内）与条数；前端类型手工移植（ADR-G-004 立场延续）
- [ ] FEATURE-004：P04 方案页「为什么」增量——plus 链条渲染 / free 模糊占位双态；**代码级，不回炉生成**
- [ ] FEATURE-005：复盘聚合端点——按自然季度聚合快照与应急目标，返回三件内容；免费全量
- [ ] FEATURE-006：P09 季度复盘页（`/tracking/review`，新，走 Open Design 生成）+ P05 追踪页复盘入口（代码级）

### 5.2 不包含（Out of Scope）

- [ ] OUT-001：支付 / 订阅 / 产品内升级路径——本期 plus 唯一开通方式 = 运维脚本；接支付届时另立 PRD（通道与合规模块均未备）
- [ ] OUT-002：P2 假设面板（可调 / 多套）与 P3 情景推演——依赖模拟引擎（μ/σ/通胀假设体系），未建
- [ ] OUT-003：推理链「规则原文 / 输入 / 匹配分支」结构化深钻——现有推理记录为裁剪形状（规则名/输出值/一句话依据，依据已内联）；扩展形状届时随 P2 假设面板一起设计
- [ ] OUT-004：历史版本方案的推理链回看——无方案历史端点；各版本链条已冻结在库，随「版本回看」功能一起做

- [ ] OUT-006：复盘 Plus 叠加（目标达成概率，产品 PRD §4.4.4）——依赖模拟引擎 V2
- [ ] OUT-007：理财金字塔（延续 F/G 期 OUT-003，前置 = 引擎层级/让位语义扩展 ADR）
- [ ] OUT-008：追踪 T5 模式切换历史对比 / T6 数据变更触发重算（追踪模块后续项）

## 6. 业务规则

> 编号承接 G 期 prd-g.md（RULE-038 ～ RULE-044），自 RULE-045 起。

- RULE-045：推理链是 Plus 能力——「怎么做」（方案数字）免费，「为什么」（推理链）Plus；闸门在服务侧：free 会话的任何接口响应体不含推理链内容，前端遮罩不算闸门。
- RULE-046：分层实时生效——账号分层变更后，已生成方案**无需重新生成**即可展开推理链（按当前分层过滤，与方案版本无关）；本期唯一分层变更方式 = 运维脚本，产品内无购买/升级/自助开通路径。
- RULE-047：推理链如实呈现——链条内容 = 引擎求解时产出并随方案版本冻结的记录（+ 本期新增的让位节点），前端不得编造、美化或省略节点；让位未发生则无让位节点。
- RULE-048：推理链覆盖范围 = 应急金三规则（月数 / 目标 / 月转入节奏）+ 让位链（发生时）；L2 配置比例的「为什么」不在链条内（由模式解读承接，OUT-005）。
- RULE-049：季度复盘按**自然季度**（Q1-Q4）聚合；缺省展示当前季度；不满整季展示至今；首份可看报告 = 2026 Q4（10-12 月）。
- RULE-050：复盘三件内容的口径——① 已坚持月数 = 全部快照自然月累计（非季内、非连续）；② 各桶季内变化 = 本季末条快照余额 − 本季首条快照余额（仅 1 条时变化记 0 并标注）；③ 缺口收敛 = 本季首条快照缺口 → 本季末条快照缺口，月均收敛与「按当前速度约 N 个月攒满」为**线性外推参考**，不构成预测承诺；「本月特殊」快照计入①、不计入②③的环比（RULE-024 延续）。
- RULE-051：季度复盘免费全量——两种分层下功能与数据完全一致；Plus 叠加（达成概率等）依赖模拟引擎，本期不做（OUT-006）。
- RULE-052：金额永不入日志与埋点（B 期立场延续）；复盘页脚免责声明沿用全站模板（RULE-020/031 模式）。

自检：以上每条均可回答「是/否」。
