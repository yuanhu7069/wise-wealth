## 3 生成预算与流程

- **预算：1 新页 × 对话式追加 1 run**（参照 D/E/F/G 期同类耗时 ≈ 4-10 min/run）；产物不满意走**对话式修改**，不从零重生成。
- 流程：P09 追加生成 → T1 → 固化 → P09 落地 → T2。
- 生成提示词内容：以真实复盘形态为样例——三卡（已坚持 N 个月大数字卡 / 各桶变化列表含带符号金额与负数红字 / 缺口收敛卡含「按当前速度约 N 个月攒满」距离感表述）、季度切换器（当前季高亮）、空态（「这一季还没有快照」+ 引导按钮）、单点形态（「本季仅 1 条快照」）、「本月特殊，未计入变化」标注、页脚免责声明。
