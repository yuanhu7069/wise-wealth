## 1. 页面结构层（P01 工程骨架首页）

桌面优先，内容区 max-width 1200px，页面边距 --space-xxl。三个区块自上而下：

1. **头部**：品牌名「智策理财」（--text-page-title）+ 版本号（--text-data，等宽数字）+ 「工程骨架 A 期」Badge 徽标
2. **健康状态卡片**：全页唯一交互区，五态齐全（见 §2），右侧配「重试」文字按钮（错误态可见）
3. **Token 样例区**：色板 / 字阶 / 间距 / 圆角 / 阴影五组静态样例，每格下方以 --text-label 标注 Token 名（如 `--color-primary`）。样例区即后续页面的 Token 速查区，B 期开发对照用
4. **免责声明区**：智策产品 PRD §13.1 免责声明模板原文全量，--text-aux 字阶，720px 阅读宽度居中（design 基线 §6.4）

## 2. 状态卡片组件（本期唯一新建交互组件）

页面级五态映射为卡片的三种视觉形态：

| 卡片形态 | 覆盖的页面五态 | 视觉规则 |
|----------|--------------|---------|
| 骨架屏 | 默认态 + 加载态 | shadcn Skeleton（Tailwind animate-pulse），形状接近真实内容；/health 请求 >300ms 才渲染（design 基线 §7.2 骨架屏阈值） |
| 错误态 | 错误态 | ERR-001（后端不可达）或 ERR-002（库不可达）文案 + danger 色图标 + [重试] 文字按钮。文案三要素齐全，文案唯一来源见 §5 |
| 成功态（含空态说明） | 成功态 + 空态 | success 色图标 + 「服务在线 · 数据库已连接 · vX.Y.Z」（版本号 --text-data）+ 空态三要素说明：Compass 图标 + 「服务在线，暂无业务模块……」人话说明 + 引导句（指向产品 PRD 文档） |

> 空态三要素（design 基线 §7.3）：图标（Compass）+ 一句人话说明 + 一个明确引导。禁止裸「暂无数据」。

## 3. Token 落地（@theme）

落地位置：`web/src/app/globals.css`，Tailwind v4 `@theme inline` 语法。

- **唯一值来源**：design 基线 §5.1.1（亮色色板）/ §5.1.2（暗色映射）/ §5.2（字阶）/ §5.3（间距）/ §5.4（圆角）/ §5.5（阴影）。globals.css 从基线逐 Token 抄入，基线是唯一值来源，本文件与代码都不另造第二份值表
- **Tailwind v4 机制**：`--color-X` 自动生成 `text-X / bg-X / border-X` 工具类；`--text-*` 生成字号工具类；间距、圆角、阴影同理。因此落地即得语义工具类（`bg-page`、`text-aux`、`border-divider` 等）
- **shadcn 主题覆盖**：shadcn 默认 slate 色板必须全部映射到苑问色板（主色 #4A6B57 松墨绿），禁止保留默认色（design 基线红线、arch 基线 §5.5 第 3 条）
- **门禁**：`scripts/check.sh` 增加 Token 门禁——grep 扫描 `web/src` 下 `.ts/.tsx` 文件中的十六进制色值与裸 px 数值，`globals.css` 除外。命中即失败（AC-6 自动化）

## 4. 暗色模式实现

- `:root` 定义亮色值；`@media (prefers-color-scheme: dark)` 按 design 基线 §5.1.2 逐 Token 重定义
- A 期不用 `.dark` class 策略与 `@custom-variant`（无手动切换）；B 期加手动切换时再引入
- 验收：DevTools 模拟暗色走查，无纯黑背景与纯白文字，对比度按 design 基线 §10 速查表核对（AC-7）

## 5. 文案与图标

**文案唯一来源原则**：P01 全部用户可见文案以 prd-a.md §8.4（ERR-001/002/003、LOADING-001）与 §7.1（成功态/空态文案示例）为唯一来源，本文件只列位置与 Token，不复制文案，避免双处维护。

**文案 → Token 对应**：

- 头部品牌名：--text-page-title；版本号：--text-data（等宽数字）；A 期徽标：--text-label
- 状态卡成功态：--text-body + 版本号 --text-data
- 错误态文案：--text-body
- 空态说明 + 引导句：--text-body + --text-aux
- 免责声明区：--text-aux，720px 阅读宽度

**图标（Lucide，线性，线宽 2，常规尺寸 20px）**：

- 状态卡成功态：`CircleCheck`（--color-success）
- 错误态：`ServerOff`（ERR-001）或 `Database`（ERR-002），配 --color-danger
- 空态：`Compass`（--color-text-aux）——产品隐喻：理财罗盘，呼应「智策」
- 头部品牌旁与免责声明区不放图标（克制原则）

## 6. 动效登记（design 基线 §8.3，Level C 推荐执行）

- A 期唯一动效 = 骨架屏 pulse，时长取 Tailwind animate-pulse 框架默认（≈2s；框架默认值不算发明数值，design 基线 §8.1 微交互 120-160ms 规则针对 hover/press 类，不针对骨架屏）
- 触发条件 = /health 请求进行中且已 >300ms（300ms 阈值出自 design 基线 §7.2 骨架屏规则）；取消条件 = 响应到达即结束
- 降级 = `prefers-reduced-motion: reduce` 时动画归零、骨架静止，功能不受影响（AC-9）
- 同屏同时进行的动效数量 = 1（design 基线 §8.2 第 2 条）
