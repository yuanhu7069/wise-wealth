| README 红线、命令与升级路径 | grep 断言红线原句、备份/演练命令、升级前先备份 | ✓ |

**保留窗口为什么是「7 个日历日 + 5 个 ISO 周」**:基线 §7.3 要求至少能回退到 7 天前与 1 个月前。
按「最新 7 个文件」保留时,一天跑多次只覆盖一天多;按 4 个 ISO 周最老只到 22 天 —— 两者都不达标。
故按日历日计数,并把周备从 4 加到 5(实测最老一份 35 天)。

备份文件本身不在此处枚举:它们按保留策略轮转,写进报告那一刻起就在变;下面演练记录里那份是当次演练所用的。
