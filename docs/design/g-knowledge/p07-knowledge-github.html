标准普尔象限:被讲了几万遍的『家庭资产配置图』

存疑

网传按 10/20/30/40 切分家庭资产的四象限图;流传极广,但出处站不住——本篇只讲它说了什么,不做背书。

理论来源

这张图在国内流传时,常被描述为「标准普尔公司调研全球十万个资产稳健增长的家庭,分析总结出他们的理财方式」。我们把能找到的公开资料翻了一遍:标准普尔(现标普全球)的公司出版物、官网存档与媒体数据库里,都没有这份报告的痕迹。

能查到的最早中文版本,出现在 2011 年前后的保险行业培训材料与博客转载里。此后它被课件、讲座与短视频反复转印,「出处」一栏却始终空着——引用它的文章,大多也说不清自己是从哪里看来的。

核心逻辑

图的内容不复杂:把家庭资产按用途切成四份。要花的钱覆盖 3-6 个月日常开销;保命的钱专款专用,应对突发风险;生钱的钱承担波动、追求收益;保本的钱追求稳健保值。四笔钱各占 10%、20%、30%、40%,互不挪用。

抛开出处问题,「按用途分桶、专款专用」的思路与现金管理的通行做法并不冲突。它的问题不在结论,而在证据:比例是拍出来的,不是研究出来的。

适用条件

如果你需要的只是一个「开始分账」的提醒,这张图能起到提示作用:先把要花的钱留出来,再谈投资。对从未做过任何规划的人,一个简单的默认比例,总好过没有比例。

但它不适合被当作精确的配置依据。家庭负债、收入稳定性与人生阶段,都会让同一个比例失真——「人人通用」是它作为传播物的优点,也是它作为工具的缺点。

局限性

最主要的问题是借名:它借「标准普尔」的名字获得了不属于它的权威性。一张没有交代研究方法的图,无法回答「为什么是 10/20/30/40,而不是 15/20/35/30」这类问题。

其次是比例僵化。它默认所有家庭结构相似、风险偏好相似、生命周期相似;而同一比例,对刚工作的单身者与赡养两位老人的中年家庭,含义完全不同。作为分账的起点可以参考,作为配置结论照搬,我们不建议。

美林时钟

仅供理解,不建议照搬

逻辑优美,周期难测,事后看图完美,事前下注全靠猜。

它说什么

美林时钟把经济周期分成复苏、过热、滞胀、衰退四个阶段,按经济增长与通胀两个坐标轮动,主张不同阶段配置不同资产:复苏配股票,过热持大宗商品,滞胀拿现金,衰退配债券。

它的原型是美林证券 2004 年的研究《The Investment Clock》,基于美国 1973-2004 年的数据回测。这份研究真实存在——这一点与「标准普尔象限图」的凭空出现不同。

为什么它流行

它把复杂的宏观周期画成一个可以转动的圆盘,几分钟就能复述。这种「一张图讲清一切」的性质,天然适合讲座与短视频传播。

它也给了投资者一种秩序感:只要判断对季节,就能选对资产。这种确定性,在充满不确定的市场里格外有吸引力。

为什么不建议照搬

周期难以实时判断。事后看图,每个阶段都清清楚楚;事前下注时,你未必知道自己正处在哪个阶段——而时钟不会等你确认了再转。

个人投资者既没有数据优势,也缺少纪律保障。机构用它做配置研究尚且经常踏错;个人照搬,很容易沦为频繁调仓的依据。学术上颇有章法,工具上并不落地——这正是它被放进「不可落地专区」的原因。
