## 承 D 期定稿（逐字沿用）

- 语言：界面文案一律简体中文，沿用现有页面真实文案与信息架构；不新造功能、不增删字段
- 主题：亮 / 暗两套都要（现有三态切换 跟随系统→亮→暗 的行为保留）
- 五态：每页齐备 空 / 加载 / 错误 / 空结果 / 正常，不接受只给正常态
- 极端数据：金额超长（¥12,345,678.90）、标题超长截断、列表 0 条与海量、负数
- 数值：等宽数字、千分位、右对齐
- 中文渲染：标题不用负字距、细体加重一档，正文行高放宽
- 无障碍：正文对比度 ≥ 4.5:1，焦点可见、键盘可达
- 自包含：不引用外部 CDN / 在线字体；中文回退 PingFang SC / Microsoft YaHei
- 移动端：375px 可用，触控目标 ≥ 44px
- 边界：只设计视觉与布局；接口、数据流、业务字段一律不动

## E 期追加（P05 追踪页 · 新页生成专用）

- 视觉一致性：P05 是既有四页体系里的**新页**，token 只用既有契约值，不发明任何新色值/字阶/间距；组件形态对齐既有分区卡、提示条、pill 按钮语汇
- 页面结构（单页五段纵排，段序固定）：
  1. **快照录入卡**：3-4 个数字输入框（桶名来自方案，数量可变），逐桶输入 + 实时千分位预览；「本月特殊」勾选项（含一句话解释）；主按钮「记录本月」；错误态下输入保留
  2. **距离感进度**：文本为主——「还差 X 个月攒满应急金」「已坚持 Y 个月」；达标态为绿色变体（「应急金已达标，缺口 0 个月」）
  3. **偏离提示条**：温和文案两变体（上涨/下降方向各一），含「标记为本月特殊」行动点；不触发时整段不占位
  4. **历史快照列表**：按月倒序；行 = 月份 + 各桶余额（等宽右对齐，负数红字）+ 特殊标记徽标；空态 = 首月引导文案
  5. **导出区**：两个次级按钮（导出快照 CSV / 导出方案 CSV）；快照为 0 时置灰
- 布局变体必须同时给出：桶数 = 3（50/30/20）与桶数 = 4（四账户）两种录入卡形态
- 空态与引导：无任何快照时的「第 1 个月，从这里开始」首录引导；无方案时的「还没有方案，先去生成一份」整页空态
- 语义色规则（沿用项目既定，覆盖 design system 默认）：负数/下降 = 红，增长/达标 = 绿
