## 1 背景与目标

Phase 1 已于 G 期收口。本期开 Phase 2「Plus 基础」：P1 推理链展开（产品 PRD §5.1，数据 B 期起已随方案冻结在库，本期暴露 + 引擎补让位节点）+ 追踪 T4 季度复盘（§4.4.3，免费全量，自然季度聚合）。Plus 闸门在服务侧按 `users.tier` 实时过滤（迁移 0002 预留字段启用）；无支付，置 plus = 运维脚本。

**边界**：solve 金额语义零改动（增补仅追加输出，ADR-H-002）；数据库零迁移（连续第三期）；复盘 Plus 叠加（达成概率）不做（依赖模拟引擎）；金字塔挂账延续；P04/P05 增量代码级不回炉。

## 2 已定决策（grilling 两轮 · 2026-09-27，苑问拍板「按照推荐」）

| 决策点 | 结论 |
|---|---|
| 期范围 | P1 推理链展开 + T4 季度复盘（一 Plus 一免费，互不纠缠）；金字塔继续挂账 |
| Plus 闸门 | 启用 `users.tier`（free/plus），服务侧实时过滤；free 响应体无链条内容、仅条数；前端遮罩不算闸门；置 plus = `scripts/set-tier.sh`（运维 SQL），产品内无购买路径 |
| 免费态呈现 | 「为什么」入口可见 → 点击出 Plus 徽章 + 模糊占位 + 一句示例 + N 步计数；转化钩子可见 |
| 推理链范围 | 应急金三规则 + `safety_first_yield` 让位节点（仅让位发生时，引擎输出追加）；L2 配置比例的「为什么」由模式解读承接（OUT） |
| 复盘语义 | 自然季度（Q1-Q4），缺省当前季，不满整季展示至今，首份 = 2026 Q4；三件内容：坚持月数（全量累计）/ 各桶季内变化（首末快照差）/ 缺口收敛（月均 + 「按当前速度约 N 个月」线性外推）；特殊月计坚持、不计环比 |

| tier 运维 | `scripts/set-tier.sh <username> <free|plus>`；分层实时生效，已生成方案无需重新生成 |
| 时间盒 | 2026-09-28 → 2026-10-15；REQ-20260927-01 |
| 埋点 | `page_view` p09（白名单扩）；推理链展开不单独埋（页面内动作，沿 G 期先例） |

## 3 流程

域层 + 服务层按 arch-h 常规分层（引擎唯一改动点 = 让位 trace 追加）；P09 走三道闸门：


引擎增补完成门：既有金例全量回归绿 + preview 对账回归绿（RISK-H-2，任一红即回退增补）。

## 4 调整清单（落地时逐项填：调整项 | 生成原值 | 本项目值 | 理由）

> 起草：AI（草稿过闸后）；拍板：苑问。清单外一律照产物执行。

| # | 调整项 | 生成原值 | 本项目值 | 理由 |
|---|---|---|---|---|
| 1 | 多状态并排样张 | 产物一页纵排五种状态 + 极端数据核验区 | 按数据形态单态渲染(正常三卡/单点/空季),骨架 = 路由级 loading.tsx,错误 = 页级错误条 | 产物是规格样张,应用渲染真实数据形态(AC-10/13) |
| 2 | 极端数据核验区 | 产物 specimen 区(超长金额/负数大额/超长桶名/海量行) | 不落地 | 产物自述「仅排版样本,非产品界面」 |
| 3 | 特殊月标注位置 | 产物:pill 放在单个桶行(备用账户行) | 卡级说明(「2026-10 本月特殊,未计入变化」) | 数据真源是「月」不是「桶」(API special_months),月级口径不映射到桶 |
| 4 | 顶栏/页脚 | 产物内置 topbar/footer 副本(含 v1.2.0、服务正常点) | 复用应用既有 shell(全局布局 + SiteFooterShell) | 单一真源;产物副本不入代码 |
| 5 | 季度切换器 | 产物:前端循环改标签,样例数据不变 | URL 查询参数驱动(`?quarter=YYYY-QN`,只产合法值),数据随切换重取;`role=group` 落为语义 `fieldset`(biome a11y) | arch-h §1:服务端为真源;切换器只产合法值 |
| 6 | 季度标签底/框色 | 产物:accent-subtle 底 + accent 30% 描边(color-mix) | `bg-primary-soft` + `border-primary/30` | 照产物值执行(应用 token 即同值);无 `primary-border` token 用透明度修饰符 |
| 7 | 空态引导链接 | `p05-track.html` | `/tracking` | 应用路由 |

**直接复用 D/E/F/G 期结论（落地时照抄）**：中文字重 500 / 行高 1.75 / 标题零负字距 / CJK 字体栈追加 / 按钮微字距 0.02em / 卡内距沿 p-base-lg / 图标统一 lucide。

## 6 AI 硬约束

1. 参数四件套未齐不开生成；2. daemon 连不上停下报告，不手搓不换来源；3. 对话式迭代，不整项目重生成，不批量重跑；4. 生成后立即固化并补生成记录；5. 调整清单外不按审美改动；6. 草稿未过 T1 不落地；7. **金额永不进日志与埋点**；8. **solve 金额路径/签名/既有输出零改动**（让位 trace 仅追加输出；既有金例与对账回归全绿为完成门）；9. **free 响应体禁止出现链条内容**（服务侧过滤是唯一闸门，前端遮罩不算）；10. 推理链与复盘文案**不构成投资建议、不承诺收益**，外推表述明示「按当前速度约 N 个月」为线性参考。
