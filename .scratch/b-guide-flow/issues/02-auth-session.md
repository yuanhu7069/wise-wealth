# 02: 登录与会话闭环

**What to build:** 用账号密码登录后可以访问业务页面；未登录访问任何业务页面会被引导到登录页，登录成功后回到原本要去的页面；密码输错有明确提示；连续失败会被限流；可以退出登录。站点页脚（健康状态 + 一行免责声明 + 可展开的完整声明）同期就位。

**Blocked by:** None（可立即开工；与 01 互不阻塞，可并行或任意顺序）

**Status:** ready-for-agent

**切分理由：** 与 01 无阻塞边的理由：一个管数据与权限，一个管算法，二者的交集只有「档案」这个数据结构，在 04 才汇合。编号把它放在 01 之后只是因为引擎风险最高、适合先退役。

- [ ] 未登录访问 首页／问卷页／方案页 → 跳转登录页，并携带站内回跳目标
- [ ] 登录成功 → 回到回跳目标（无目标则落到首页）
- [ ] 密码错误 → 字段级提示「用户名或密码不正确」；同一来源 1 分钟内第 6 次失败 → 限流提示（复用已有 RATE_LIMITED 错误码）
- [ ] 回跳参数只接受以单个 `/` 开头的站内路径，`//evil.com` 与 `https://…` 等一律丢弃
- [ ] 无 Cookie 调用任一业务端点 → 401 信封（越权测试覆盖每个端点）
- [ ] 退出登录 → 会话失效并回到登录页
- [ ] 种子脚本可从环境变量幂等写入/重置账号密码，不打印密码
- [ ] 站点页脚：健康状态 + 一行免责声明 +「完整声明」可展开 PRD §13.1 原文（展开态切页自动收起）
- [ ] 日志不含密码、令牌或用户名原文
