# 03: 问卷作答与断点恢复（步 1-5）

**What to build:** 登录后从首页进入问卷，一次回答一个问题：这笔钱几年后要用 → 100 万跌到 70 万的第一反应 → 收入稳定吗 → 已有保障与负债 → 基础财务数字。每答完一步自动保存，中途关闭再进来停在上次答到的位置，已答内容保持选中。非法数字被字段级拦下。

**Blocked by:** 02（需要登录态保护问卷页与档案接口）

**Status:** ready-for-agent

- [ ] 步 1-5 可按顺序作答并推进，一次只显示一个问题
- [ ] 每步「下一步」成功后答案落库；重新进入问卷停在最后已完成步，且答案保持选中态
- [ ] 月收入填 0／负数／非数字 → 字段级错误文案，阻止步进
- [ ] 单选步（久期／回撤反应／收入稳定性／理财目标）未选时阻止步进并说明原因
- [ ] 房贷余额与商业保险可留空；页面明确说明「本期仅记录，不影响方案结果」
- [ ] 需赡养人数为 0-20 的整数，越界被拦
- [ ] 金额以整数分落库、以元展示；问卷页显示步进条与「每步自动保存草稿，中断后可恢复」
- [ ] 会话过期后重新登录 → 回到原步且已答内容完整
