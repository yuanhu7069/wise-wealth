# 08: 备份脚本与恢复演练

**What to build:** 一条命令产出可校验的数据库备份，并且**真的能恢复回来**——恢复到副本库后抽验数据一致。这是 ADR-A-002 在首个业务表落地时点名的兑现项：在此之前不录入不可重建的真实数据。

**Blocked by:** 05（已完成）

**Status:** done（2026-09-11）

**完成记录**：`scripts/backup.sh` + `scripts/restore-drill.sh` + README 备份/恢复/升级章节 + `docs/b/test-report-b.md` §1 演练记录。验收脚本 `.scratch/b-guide-flow/tmp-verify-08.sh` 六节全绿（退出码 0）。

**备份侧**：`pg_dump --format=custom` → `backups/wise_wealth_YYYYMMDD_HHMM.dump` + 同名 `.sha256` + 同名 `.meta`。四处刻意的设计：①**半截文件不留正式身份**——先写 `.part`，`pg_restore --list` 自检通过才改名；②保留策略按**文件名里的时间戳**判（拷贝与同步会改 mtime），且「7 天」是**7 个日历日**各留最新一份，「4 周」是 ISO 周各留最新一份——按「最新 7 个文件」保留时一天跑多次只覆盖一天多，按 4 周最老只到 22 天，够不到基线的「1 个月前」，故周备取 **5**（实测最老一份 35 天）；③`.meta` 记 git 版本、已应用迁移数与**脱敏配置快照**（非密钥项照记、密钥只记「已配置」）——基线 §7.3 的备份内容 = 数据库 + 配置（不含密钥）+ 代码版本，而本项目配置就在 `.env` 里，整份拷进备份等于把口令写进备份文件；④连接串解析不出库名时写 `unknown` 而**绝不回落到原文**（否则整条含口令的 DSN 会进 `.meta` 并被打印）。

**演练侧（AC-15）**：一条命令跑完「备份 → 副本库恢复 → 抽验 → 用副本库起服务」。抽验比的是**数据本身**：5 张表行数 + profiles 三项金额合计 + plan_buckets 两项金额合计 + plans 版本与可投资额 + plans/profiles 的 md5 内容指纹，共 10 项；最后用副本库起服务，`/health` `"db":"ok"`、**种子账号真的登录成功**（口令哈希随备份恢复）、读出方案数据。恢复用 `--single-transaction`，要么整份成功要么整份回滚；口令经 stdin 送（argv 会出现在 `ps` 里，与 `seed-user.sh` 同一条规则）。

**实测记录（2026-09-11 00:24 CST，dev 库 → 副本库 `wise_wealth_db_test`）**：备份 `wise_wealth_20260911_0024.dump`，SHA256 `0f99c5d8…f1046`，**10 项抽验全部一致**，副本库服务 `db=ok` + 可登录 + 可读方案（第 2 版 / four_accounts）。完整记录见 `docs/b/test-report-b.md` §1.2。**ADR-A-002 至此兑现，README 红线随之解除**（换库/改迁移/改恢复链路后重新生效）。

**两轮并行评审（标准轴 + 规格轴）修掉的真缺陷**——这一批脚本是本次会话里评审收益最高的：

| 缺陷 | 后果 | 修法 |
|---|---|---|
| 演练在 `APP_ENV=prod` 时只覆盖 `DATABASE_URL_DEV` | 「用副本库起服务」实际连回**正式库**跑服务 | 按 APP_ENV 覆盖对应变量 |
| 缺「副本库 ≠ 源库」的闸 | `WW_DRILL_DB` 指到源库时 `--clean` 会把源库表**删光** | 两道闸：地址必须真的换库名、且不得等于源库（已实测拒绝且源库 6 张表完好） |
| 库名未做字符白名单 | 一个引号即可改变 `CREATE DATABASE` 语句结构 | 只允许字母数字下划线 |
| 取最新备份用 `ls -t`（mtime）而保留策略用文件名 | 自相矛盾，拷进来的旧备份会被选中 | 统一按文件名排序 |
| 「日备 7 份」实现成「最新 7 个文件」 | 一天跑多次只覆盖一天多，回退不到 7 天前 | 按日历日计数（并补了同一天跑多次的用例）|
| 周备 4 份 | 最老只到 22 天，够不到基线的「1 个月前」 | 改 5 份 + 断言最老一份 ≥28 天 |
| `.meta` 在无库名段的 DSN 下写入整条连接串 | **口令进备份文件并被打印** | 解析不出即写 unknown |
| 演练用 `curl -d` 传口令 | 口令出现在 `ps` 输出里 | 改 stdin（`-d @-`） |
| 证据脚本若干断言两侧同源 / `$?` 在 `set -e` 下轮不到断言 | 永远「通过」，或失败时报成「阻塞」 | 改字面量/独立量；断言失败与阻塞分开记退出码 |
| 合成测试文件写进真实 `backups/` | 顶着今天日期，会挤掉当天真实备份、且被演练选中 | 改在临时目录里造 |
