# 08: 备份脚本与恢复演练

**What to build:** 一条命令产出可校验的数据库备份，并且**真的能恢复回来**——恢复到副本库后抽验数据一致。这是 ADR-A-002 在首个业务表落地时点名的兑现项：在此之前不录入不可重建的真实数据。

**Blocked by:** 05（业务表与真实数据链路就位，演练才有意义）

**Status:** ready-for-agent

**切分理由：** 与 09（验收走查）**不合并**：①阻塞边不同——本 ticket 只需 05，可与 06／07 并行；09 需要 06／07／08 全部完成。合并会把本可并行的工作串行化。②验证方式不同：本 ticket 是脚本产出 + 恢复抽验，09 是人工走查 + 报告。

- [ ] 备份脚本产出自定义格式转储文件 + SHA256 校验文件，并按保留策略清理旧备份
- [ ] 备份文件不落在会被提交到版本库的位置
- [ ] 恢复步骤可把备份导入副本库并成功启动服务
- [ ] 抽验：副本库中档案与方案的行数、关键金额与源库一致
- [ ] 演练记录（时间、备份文件、校验值、抽验结果）写入 B 期测试报告
- [ ] README／运维说明写明「恢复演练完成前不录入不可重建的真实数据」
